Notch is a control room for a fleet of coding agents — Claude Code, Codex, OpenCode, Grok, Antigravity — sharing one brain, passing one baton, and emitting real OpenTelemetry spans, metrics and logs into HydraDB.

This release is about making what was on screen **true**, and putting all of it on your phone.

## Offload a turn to Gemini

A new **Antigravity CLI** adapter drives Google's headless `agy` — it holds the baton and runs a turn to completion with no GUI in the loop, so any project can hand work to a flash-tier model instead of spending your orchestrator's budget. Verified end to end against `agy 1.1.6`: baton handoff, a real turn, and `--conversation` resume carrying context across turns.

## The Observatory, rebuilt

Eight tabs asked you to know the difference between Canvas and Graph, and between Replay and Time Travel, before you could look at anything. Now there are six:

- **Metrics** leads and is a real dashboard — totals, then what the spend is made of (token and turn donuts per agent/model), then behaviour over time, then per-agent health with one-click triage, then the 24h burn.
- **Live fleet** is about this second: who is running, who holds the baton, and an edge that marches while an agent is reading and writing the shared brain.
- **Handoffs** is about history: every route the baton took, labelled with how many times it took it.
- **Replay** absorbed the separate span-replay tab. One scrubber now shows both the reconstructed fleet state at a moment *and* the turn that was running then, with its model, duration, tokens, cost and trace.

## Ask Noz

An assistant docked in the Observatory: a model with your MCP servers attached, answering from the same telemetry the dashboard renders — so an answer can never cite a number the screen doesn't also show. It needs no API key of its own; the cheapest CLI you already have signed in answers it.

## MCP and Skills became real

Both were shells, and both now work end to end:

- **MCP** browses the official registry (`registry.modelcontextprotocol.io`) with search, alongside a curated row of providers whose endpoints were each verified rather than guessed. Install persists to the project, the reachability badge is a real probe, and the server is rendered into the config the CLI actually receives — verified with `claude --mcp-config` and `codex -c mcp_servers.*` against claude 2.1.193 and codex-cli 0.144.6 by running them.
- **Skills** now discovers every real root — the project, `~/.claude/skills`, and plugin caches — which turned 1 visible skill into 74. Install from a git URL or a folder, enable per project, or add one mid-sentence from the composer's `/` menu.

## Four things that were lying, fixed

An honest audit found them; all four are now implemented rather than hidden:

- **MCP servers never reached any agent.** They do now.
- **Decision confidence was a hardcoded constant** on the default install, rendered as a measured percentage. Confidence is now measured by a real extractor, is *optional*, and every decision says how it was extracted. A decision with nothing to measure says "not measured" rather than showing a fabricated number.
- **Per-decision cost was the whole turn's cost, repeated** for every decision mined from that turn. Totals are now attributed to the turn they belong to.
- **Per-agent budgets were write-only.** They now enforce: an agent over its daily cap is paused before the turn is dispatched, and un-pauses itself when it's back under.

## Notch on your phone

The mobile app reached parity with the desktop: the full six-view Observatory with charts, Decisions, Replay, Ask Noz, the Skills and MCP browsers, and project settings — native, not a webview.

## Accessibility and craft

The Observatory's tab strip scrolls instead of clipping when the pane is narrow, is a proper ARIA tablist with arrow-key navigation, and keeps keyboard focus alive across the live re-render. Charts got their own categorical palette — they were drawn from two tokens that are both violet, so a donut's three biggest slices were indistinguishable.
